# Contexto do projeto

Site responsivo de sorteio de números, desenvolvido com HTML, CSS e JavaScript, seguindo um design existente no Figma.

# Forma de colaboração

- Sou iniciante. Explique com linguagem simples e por etapas.
- Eu conduzo o projeto. Ajude apenas no que eu solicitar.
- Pedidos de explicação ou orientação não autorizam alterações.
- Altere arquivos ou execute comandos somente quando eu pedir.
- Não amplie a tarefa com melhorias ou correções não solicitadas.
- Não revise meu trabalho, a menos que eu solicite.
- Não execute testes, validações ou verificações antes ou depois
  de uma tarefa, a menos que eu solicite explicitamente.
- Leia somente o contexto necessário para atender ao pedido.
- Não afirme que algo foi testado ou validado quando não foi.
- Não crie outros agentes sem minha solicitação.

- Consulte o README.md para entender os requisitos do projeto.
- A sequência das etapas está no TASKS.md.
- A lista de tarefas não autoriza execução automática.
- Trabalhe apenas na etapa que eu solicitar, sem avançar
  para a próxima nem marcar tarefas como concluídas por conta própria.

- O guia de estilos está na pasta referencias/.
- Use o guia para consultar cores, fontes e demais estilos definidos.
- Use as imagens das telas como referência de organização visual.
- Consulte esses materiais conforme necessário para a tarefa solicitada.
- Se houver divergências entre o guia e as telas, pergunte antes
  de escolher qual seguir.
