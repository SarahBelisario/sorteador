# 🎲 Sorteador de números

Projeto em desenvolvimento de um site responsivo para sorteio de números, utilizando HTML, CSS e JavaScript, com base em um design do Figma.

## 🚧 Em desenvolvimento

O projeto está sendo desenvolvido por mim, com auxílio pontual de IA para dúvidas e tarefas solicitadas.

## ✨ Funcionalidades previstas

- Escolher a quantidade de números a sortear.
- Definir os valores mínimo e máximo.
- Permitir sorteios sem números repetidos.
- Exibir mensagens para preenchimentos inválidos.
- Apresentar os resultados com animação.

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript

## 📁 Organização

- `assets/`: imagens e ícones utilizados no site.
- `css/`: arquivos de estilos.
- `index.html`: estrutura da página.
- `script.js`: lógica do sorteador.
- `REQUISITOS.md`: requisitos detalhados do projeto.
- `AGENTS.md`: instruções de colaboração com IA.
- `TASKS.md`: etapas de desenvolvimento.

As referências visuais do Figma são mantidas apenas localmente.
